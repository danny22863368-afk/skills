# Danny 健身教練 App

單一 HTML 檔的個人健身 app,基於「一週四練・上下肢分化」課表打造。
所有資料儲存在裝置的 localStorage,離線可用。

## 使用方式

把 `index.html` 傳到手機(或直接用瀏覽器開啟),建議「加入主畫面」當 app 用。

## 功能

- **今日訓練**:自動顯示當天課表(週一上肢A/週二下肢A/週四上肢B/週五下肢B),逐組記錄重量×次數,完成一組自動啟動組間休息倒數(含提示音/震動)。
- **重量建議**:依漸進超負荷原則 —— 上次全組達到次數上限就建議加重(槓鈴 +2.5kg、啞鈴 +1–2kg、器械 +5kg);未達下限則建議維持鞏固。第一次訓練給起始重量建議。
- **今日是否練得充足**:即時比對已完成組數 vs 課表目標,給出「充足/尚可/不足」判定,並一併顯示蛋白質達成度。
- **動作推薦**:每個動作附替代選項(器材被占用或做不到時用)。
- **飲食紀錄**:內建台灣常見食物資料庫快速新增;**拍照 AI 分析**用 Claude 視覺辨識餐點、估算蛋白質/碳水/脂肪/熱量(需在設定填入 Anthropic API key,金鑰只存在裝置上)。
- **數據**:本週各肌群訓練量 vs 建議區間(胸/背 13–15 組)、臥推/深蹲/硬舉重量進展圖。
- **行事曆**:Google 日曆已建立每週一/二/四/五 19:00 的訓練提醒;課表分頁也可下載 `.ics` 匯入任何行事曆。

## 拍照 AI 分析注意事項

- 需要 Anthropic API key(platform.claude.com 取得),在 app 右上角 ⚙ 設定貼上。
- 呼叫 `claude-opus-4-8` 進行視覺辨識,回傳結構化營養資料。
- 在受 CSP 限制的線上預覽環境(如 Artifact)外部連線會被封鎖;把本檔案存到裝置本機開啟即可正常使用。
